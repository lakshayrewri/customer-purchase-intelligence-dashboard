# Customer Purchase Intelligence Dashboard

An end-to-end Data Analytics project built using **Python, PostgreSQL, and Power BI** to analyze customer purchasing behavior and generate actionable business insights.

## Tools Used

- Python (Pandas)
- PostgreSQL
- SQL
- Power BI
- DAX

## Project Workflow

1. Cleaned and transformed customer data using Python.
2. Created engineered features such as Age Group and Purchase Frequency.
3. Loaded the cleaned data into PostgreSQL using SQLAlchemy.
4. Performed business analysis with 15 SQL queries.
5. Built an interactive Power BI dashboard.

## Dashboard KPIs

- Total Customers
- Total Revenue
- Average Purchase Amount
- Average Review Rating

## Dashboard Insights

- Revenue by Category
- Orders by Season
- Revenue by Age Group
- Subscription Status
- Payment Method Distribution
- Revenue by Purchase Frequency

## SQL Skills Demonstrated

- GROUP BY
- CASE
- Subqueries
- CTEs
- Window Functions
- Ranking
- Aggregations
